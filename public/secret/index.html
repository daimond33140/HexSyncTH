📄 Process 1.0 (จัดการสมาชิก) 📄 Process 2.0 (ขายสินค้า) 📄 Process 3.0 (สั่งซื้อสินค้า) 📄 Process 4.0 (รับสินค้า)

📋 สรุป Process 1.0 (ระบบสมัครและจัดการข้อมูลสมาชิก):

  • Entity: สมาชิก
  • Processes: 1.1 ตรวจสอบข้อมูลการสมัคร, 1.2 บันทึกข้อมูลสมาชิก
  • Data Store: D1 ข้อมูลสมาชิก (สัญลักษณ์ Gane & Sarson)

📋 สรุป Process 2.0 (ระบบขายสินค้าและออกใบเสร็จ):

  • Entity: ลูกค้า / สมาชิก, พนักงาน
  • Processes: 2.1 ตรวจสอบสต็อก, 2.2 คำนวณราคา, 2.3 บันทึกการขาย, 2.4 ออกใบเสร็จ
  • Data Store: D1 ข้อมูลสมาชิก, D2 ข้อมูลสินค้าและสต็อก, D3 ข้อมูลการขายสินค้า

📋 สรุป Process 3.0 (ระบบสั่งซื้อสินค้า):

  • Entity: พนักงาน, ผู้จัดการ/เจ้าของกิจการ, ตัวแทนจำหน่าย
  • Processes: 3.1 ตรวจสอบจุดสั่งซื้อ, 3.2 จัดทำใบเสนอซื้อ, 3.3 พิจารณาและออกใบสั่งซื้อ
  • Data Store: D2 ข้อมูลสินค้าและสต็อก, D4 ข้อมูลตัวแทนจำหน่าย, D5 ข้อมูลการสั่งซื้อสินค้า

📋 สรุป Process 4.0 (ระบบรับสินค้าและชำระเงิน):

  • Entity: ตัวแทนจำหน่าย, พนักงาน
  • Processes: 4.1 ตรวจสอบสินค้า, 4.2 บันทึกรับสินค้า, 4.3 ดำเนินการชำระเงิน
  • Data Store: D5 ข้อมูลการสั่งซื้อสินค้า, D6 ข้อมูลการรับสินค้า, D2 ข้อมูลสินค้าและสต็อก
